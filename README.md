# Алгоритмы и структуры данных

Практические работы по дисциплине "Алгоритмы и структуры данных", 3 семестр.

Климашевский Даниил, группа ЭФБО-07-25

- practice1 - графы: матрицы смежности и инцидентности, эйлеровы циклы, маршруты
- practice2 - алгоритм Дейкстры
- practice3 - максимальный поток, алгоритм Форда-Фалкерсона
- practice4 - минимальное остовное дерево, независимое множество, раскраска, знаковые графы, модель Уоттса-Строгатца
- practice5 - DFS и BFS (три задания)
- practice6 - алгоритмы Беллмана-Форда и Флойда-Уоршелла, арбитраж валют
- practice7 - алгоритм A*, эвристики, сравнение с Дейкстрой
- practice8 - минимальное остовное дерево: Краскал, Прим, DSU

В работах 1-4 задачи решались вручную, в блокнотах проверка ответов через networkx.
Для запуска нужны networkx и matplotlib.
